## Forja Mistyc - Login

App Flutter só com a entrada do jogo.

1. Suba estes arquivos no GitHub (branch main).
2. Aba Actions > Build APK > aguarde.
3. Baixe o APK em Artifacts.

API real: edite `apiBaseUrl` e a classe `AuthApi` em lib/main.dart.
Servidores em `regions` são exemplo; troque pelos reais.
